# AGENTS.md

Инструкции и контекст проекта для AI-ассистентов и разработчиков:

- **Суть проекта**: Универсальный локальный OpenAI-совместимый прокси и ротатор API-ключей для любого вышестоящего провайдера (настраивается через переменную `BASE_URL`).
- **Точка входа**: `proxy.py` (FastAPI / Uvicorn).
- **Ключи**: Читаются построчно из файла `api-keys.txt`. Категорически запрещено коммитить реальные ключи в репозиторий. Для примера используется `api-keys.example.txt`.
- **Зависимости**:
  - Python: `requirements.txt` (`fastapi`, `uvicorn`, `httpx`).
  - Node.js (опционально, для OpenCode): `package.json`.
- **Запуск**:
  - Сервер: `run.bat` (Windows) или `run.sh` (Linux/macOS). По умолчанию слушает `http://127.0.0.1:8000`.
  - OpenCode агент: `run-opencode.bat` (Windows) или `run-opencode.sh` (Linux/macOS).
- **Ротация и Failover**:
  - Алгоритм Round-Robin через `itertools.cycle`.
  - При ошибках HTTP 401, 402, 403, 429, 500, 502, 503 или таймаутах/сетевых ошибках запрос автоматически перенаправляется на следующий доступный ключ (максимум попыток = количество ключей).
  - Подменяет заголовок `Authorization: Bearer <key>` на текущий ключ из пула.
- **Поддерживаемые эндпоинты**:
  - `GET /` — healthcheck со статусом, базовым URL апстрима и количеством загруженных ключей.
  - `GET /v1/models` — список доступных моделей (настраивается через `AVAILABLE_MODELS`).
  - `POST /v1/chat/completions` — генерация ответов (поддерживает SSE стриминг `stream: true`).
  - `POST /v1/responses` — OpenAI responses API.
- **Переменные окружения**:
  - `BASE_URL` (по умолчанию `https://api.your-provider.com/v1`) — URL вашего целевого провайдера.
  - `TIMEOUT` (по умолчанию `60` секунд) — таймаут запроса.
  - `HOST` (по умолчанию `127.0.0.1`) — локальный хост биндинга.
  - `PORT` (по умолчанию `8000`) — локальный порт прокси.
  - `API_KEYS_FILE` (по умолчанию `api-keys.txt`) — имя файла с ключами.
  - `AVAILABLE_MODELS` (по умолчанию `default-model,gpt-4o,claude-3-5-sonnet`) — список моделей для эндпоинта.
